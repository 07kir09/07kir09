## Избранные проекты

### 1) Risk Calculator for MOEX SPFI Market
**Флагманский финтех-проект**, посвящённый анализу рисков на рынке СПФИ Московской биржи.

**Что реализовано:**
- загрузка рыночных данных из **MOEX ISS API / CSV**;
- расчёт **риск-метрик**: **VaR, ES, Greeks / DV01**;
- поддержка **стресс-сценариев** и **stress P&L**;
- **веб-интерфейс** с фильтрами, графиками и экспортом;
- **REST API** для интеграции frontend/backend компонентов.

**Технологии:** Python, FastAPI, React, TypeScript, PostgreSQL, Redis, Docker, CI.

🔗 Репозиторий: <a href="https://github.com/07kir09/Risk-Calculator-for-the-Moscow-Exchange-SPFI-Market">Risk-Calculator-for-the-Moscow-Exchange-SPFI-Market</a>

---

### 2) HSE Bank Finance Management
Проект для работы с **банковскими счетами, транзакциями, балансами, импортом/экспортом данных и финансовой аналитикой**.

**Ключевые возможности:**
- импорт и экспорт в **CSV / JSON / YAML**;
- автоматический **пересчёт балансов** по операциям;
- **аналитика доходов и расходов**, группировка по категориям, месячная статистика;
- архитектурный подход с использованием **SOLID, GRASP, Command, Decorator, Facade**.

🔗 Репозиторий: <a href="https://github.com/07kir09/BankHSEProject">BankHSEProject</a>

---

### 3) CourseProject — Secure Data Tokenization
Web3-проект, посвящённый безопасному хранению и обработке пользовательских данных с помощью **блокчейна, шифрования и децентрализованного хранилища**.

**Ключевые возможности:**
- авторизация через MetaMask;
- загрузка JSON и хранение в **IPFS**;
- защищённый поток данных с использованием **AES + blockchain-based key handling**;
- интеграция со smart contracts;
- восстановление, расшифровка и визуализация данных в интерфейсе.

🔗 Репозиторий: <a href="https://github.com/07kir09/CourseProject">CourseProject</a>

---

### 4) Lean.Lab Telegram Bot
Telegram-бот в более приближенном к production формате: с **платежами, тарифами и развёртыванием на сервере**.

**Ключевые возможности:**
- анкета по питанию и расчёты;
- интеграция с **YooKassa**;
- тарифы **Free / Lite / VIP**;
- Docker-based deployment и серверная конфигурация.

🔗 Репозиторий: <a href="https://github.com/07kir09/Lean_Lab_TG_Bot">Lean_Lab_TG_Bot</a>
